# Folder Upload Foto

Folder ini (`/public/uploads/`) disiapkan untuk menampung file upload foto tambahan atau hasil karya visual yang ingin dimasukkan ke dalam direktori web project.

## Cara Menggunakan:
1. Letakkan foto baru Anda di folder ini (`/public/uploads/`).
2. Akses foto tersebut melalui web dengan URL:
   `/uploads/nama-file.jpg`
