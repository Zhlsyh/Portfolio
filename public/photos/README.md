# Folder Foto & Portofolio

Folder ini (`/public/photos/`) digunakan untuk menyimpan file gambar/foto portofolio Anda secara langsung di dalam direktori web project.

## Cara Menggunakan:
1. Simpan file foto Anda (contoh: `wisuda-1.jpg`, `event-etime.png`, `banner-cetak.webp`) ke dalam folder ini (`/public/photos/`).
2. Di dalam aplikasi web, Anda bisa mengakses foto tersebut menggunakan URL relatif seperti:
   `/photos/nama-file-foto.jpg`

---
*Folder siap digunakan untuk upload dan penyimpanan foto portofolio.*
